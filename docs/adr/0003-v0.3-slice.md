# v0.3 is four read-only container tools

The first verified slice is spec v0.3: `container.list` / `inspect` / `logs` / `status_summary` behind `ContainerInfoProvider`, Arcane as the only adapter, redaction, PolicyEngine, and JSONL AuditLog.

v0.3 does not listen on a port, does not register Pi's coding tools, and has no filesystem tools. Later bash / edit / write, if any, will be Thebe-owned tools with resource-scoped audit (tool + path/cwd + argument digest), not Pi builtins turned on. The spec stays in the parent `thebe/docs/` tree; this repo's `docs/` is ADRs and glossary only. Ask is one question through Pi, not a separate Thebe CLI suite.
