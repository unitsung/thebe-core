# Grok Build TUI: tasks and subagent interaction

Research snapshot: `xai-org/grok-build` commit [`3794978`](https://github.com/xai-org/grok-build/tree/37949780c144e37df692e3d669051a21fec24f20) (inspected 2026-09-13).

## User flow

1. **Discover/open tasks.** In the full-screen agent TUI, `Ctrl+G` toggles the tasks pane (`Ctrl+T` is the separate todos pane). The pane may also auto-open when its running-item count changes from zero to nonzero. Minimal mode has no interactive tasks pane; there, `/tasks` only prints a snapshot. ([user guide](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md#the-tasks-pane-tui), [shortcut reference](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/03-keyboard-shortcuts.md#global-shortcuts), [pane source](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/views/tasks_pane.rs#L960-L980), [minimal-mode source](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/slash/commands/tasks.rs#L1-L2))
2. **List/select a child.** Children are at the top in a collapsible **Subagents** group. Rows are grouped by agent type, with running rows before finished rows; a row shows the resolved agent/persona/role label and task description, and status color distinguishes running, completed, and failed. Navigate with the pane's list controls (`↑`/`↓` or `j`/`k`); `Left`/`Right` collapses/expands the selected group header. Finished children are hidden by default; `h` toggles their inclusion. ([user guide](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md#the-tasks-pane-tui), [row construction](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/views/tasks_pane.rs#L333-L416), [sorting/filtering](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/views/tasks_pane.rs#L848-L946))
3. **Open and inspect the exact task.** With a child row selected, press `Enter` or `Ctrl+F`; the same framed view opens by selecting a subagent lifecycle block in the parent scrollback and pressing `Enter`/`Ctrl+F`. The short pane row is only a description. The framed view contains the child's full transcript, and the implementation records the actual task prompt from the child's streamed/persisted `UserMessageChunk`, so the child transcript's `UserPrompt` is the exact child task/prompt rather than a reconstructed pane label. ([open-key source](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/app/agent_view/panes.rs#L898-L932), [user guide](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md#viewing-subagents-in-the-tui), [prompt provenance](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/app/subagent.rs#L4-L20))
4. **Watch live progress/tool activity.** Without opening the child, its parent lifecycle block and tasks-pane row show a live activity label such as `Thinking`, `Running: cargo test`, `Compacting`, or retry state; the pane also shows spinner/status and elapsed time. Opened, the framed view streams the child's own scrollback, thinking, and tool calls, while its title bar shows status, type/description/model, activity, and elapsed time. ([user guide](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md#viewing-subagents-in-the-tui), [live row source](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/views/tasks_pane.rs#L371-L399), [frame source](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/app/agent_view/render.rs#L620-L721))
5. **See completion/final response.** A blocking child's original lifecycle block changes state when it finishes; a background child adds a completed/failed/cancelled block. Opening a finished child replays its persisted full transcript, including tool history, the final assistant response, and a `TurnCompleted` footer. ([user guide](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md#scrollback-parent-conversation-history), [replay test](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/app/acp_handler/tests/subagents.rs#L1052-L1112))
6. **Close/return.** Press `q` or `Esc`, or click the frame's `[✗]`, to return to the parent. The parent's lifecycle block remains and continues reflecting status. In the tasks pane itself, `Ctrl+G` closes it; `Tab` moves to the prompt, while ordinary overlay navigation can return focus to scrollback. ([user guide](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md#fullscreen-framed-view-the-child-transcript), [close handling](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/app/agent_view/input.rs#L362-L396), [pane handling](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/src/app/agent_view/panes.rs#L885-L897))

## Practical distinction

The tasks pane is the roster/status surface; the fullscreen child transcript is the inspection surface. The parent scrollback is a second entry point and preserves lifecycle visibility after returning. Child views are primarily observational, not normal interactive sessions for sending new top-level prompts. ([first-party subagent guide](https://github.com/xai-org/grok-build/blob/37949780c144e37df692e3d669051a21fec24f20/crates/codegen/xai-grok-pager/docs/user-guide/16-subagents.md#fullscreen-framed-view-the-child-transcript))
